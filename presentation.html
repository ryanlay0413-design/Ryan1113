🚀 科技發展研討會 - 智慧 LINE 助手

結合 LINE Official Account + LINE LIFF + Cloudflare Workers AI

核心特色：免下載額外 App，直接在 LINE 裡面完成「議程查詢、一鍵報名、AI 科技問答與問題回報」。

a. 這個產品怎麼用它？

  • 步驟 1（加入好友）：掃描 QR Code 加入「科技發展研討會」官方帳號。
  • 步驟 2（開啟 LIFF 議程）：點擊下方圖文選單，開啟內嵌網頁瀏覽最新科技議程，點擊「一鍵報名」即可自動發送報名訊息。
  • 步驟 3（AI 科技問答）：直接在聊天室輸入任何科技問題（例如：「什麼是邊緣 AI？」），Cloudflare AI 助手會即時為您解答。

b. 如果有一些問題，我要怎麼回報？

  • 方式一（LIFF 頁面一鍵回報）：在議程網頁最下方點擊「⚠️ 遇到問題？點此回報給大會」按鈕，系統會自動帶出回報格式。
  • 方式二（聊天室關鍵字回報）：直接在 LINE 對話框輸入「問題回報：您的問題內容」，後台人員與系統會立即收到通知並協助處理。

💡 系統架構說明：前端網頁託管於 GitHub Pages，後端問答串接 Cloudflare 每日免費 10,000 Neurons 額度的 Llama-3 模型。
